## 1. Definition of Workflow

| Колонка | Картка потрапляє сюди, коли | Картка виходить звідси, коли |
| --- | --- | --- |
| Backlog | крок над ЛР5/ЛР6 визначений, але ще не продуманий настільки, щоб братися | з'явився зрозумілий результат і розмір день-два — тоді переходить у Ready |
| Ready | зрозуміло, що вважається завершенням кроку, і він розбитий до розміру одного-двох днів | я реально почав над нею працювати — перший рядок/правку внесено в потрібний файл |
| In progress | над карткою справді ведеться робота прямо зараз | проміжний результат можна прочитати або відкрити для перевірки: чернетка розділу, таблиця, список готові до читання |
| Review | результат можна прочитати й звірити з умовою роботи (ЛР5/ЛР6) | перечитано ще раз і відповідає умові — явних розбіжностей з `lr05_task.md`/`lr06_task.md` не лишилось |
| Done | пройшла Review без зауважень | — (кінцева колонка) |
